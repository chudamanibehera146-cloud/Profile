# Personal Profile Website

A single-page, responsive profile website for an AI / Machine Learning professional. Built with plain HTML and CSS, with no frameworks or dependencies.

## Features

- Hero section with name and tagline
- Focus area: Artificial Intelligence / Machine Learning
- Languages with proficiency bars (English, Hindi, Odia)
- Hobbies: Gaming, Reading books, Exploring new things
- Mobile-friendly layout
- Automatic light and dark mode

## Files

| File | Description |
|------|-------------|
| `profile.html` | The complete website (HTML + CSS in one file) |
| `README.md` | This file |

## How to Use

1. Download `profile.html`.
2. Double-click it to open in any web browser.

No build step or installation is needed.

## Customize

Open `profile.html` in a text editor and change:

- **Name:** replace `Your Name` in the `<title>`, the `<h1>`, and the footer.
- **Intro text:** edit the paragraph with class `lead`.
- **Colors:** adjust the CSS variables at the top of the `<style>` block (`--accent`, `--accent2`, etc.).
- **Language levels:** change the `width` percentage in each `.bar i` element.
- **Hobbies:** edit or add `.hobby` cards in the Hobbies section.

## Deploy for Free

- **GitHub Pages:** push the files to a repo, rename `profile.html` to `index.html`, then enable Pages in repository settings.
- **Netlify / Vercel:** drag and drop the folder, with the HTML renamed to `index.html`.
